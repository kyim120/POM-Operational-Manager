# **OPERATIONS MANAGER – COMPLETE WORK DONE**

### ✔ 1. **Designed the Entire Operational Workflow**

I created a clear step-by-step workflow from receiving the order to delivering it to the customer.

### **Order-to-Delivery Workflow**

1. Customer places order on Instagram/Website
2. Details are confirmed via DM/WhatsApp
3. Product is sent to printing/production
4. Fabric quality check is performed
5. Product is packed in branded packaging
6. Courier assigned (TCS/Leopards/Swyft)
7. Order is delivered within 2–3 days
8. Customer receives order confirmation & review request

This structured system increases efficiency and customer satisfaction.
